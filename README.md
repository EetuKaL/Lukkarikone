# Lukkarikone
Hae suoraan oman ryhmän tiedot lukkarikoneesta.

# Ryhmän asettaminen
1. Napsauta Firefoxin työkalupalkissa Lukkarikoneen kuvaketta.
2. Syötä ryhmän nimi popup-ikkunaan ja valitse **Tallenna**.
3. Avaa tai lataa uudelleen Lukkarikoneen sivu.

# ASENNUS FIREFOX
### Firefox laajennuskaupasta
1. Lataa ja asenna firefox laajennuskaupasta
### Manuaalisesti lataamalla xpi-tiedosto.
1. A) Lataa lukkarikone.xpi-tiedosto.
1. Avaa firefoxissa: about:debugging#/runtime/this-firefox
2. Valitse Load Temporary Add-on...
3. Valitse ladattu xpi-tiedosto.
4. Avaa Lukkarikoneen sivu
